# JavaScript Essential

A beginner-friendly collection of JavaScript mini-projects and exercise folders focused on core web development concepts. This repository demonstrates how to build practical browser-based features using HTML, CSS, and JavaScript.

## Overview

This project contains multiple standalone examples covering:

- JavaScript fundamentals
- DOM manipulation
- Events and user interaction
- Arrays, objects, and functions
- Conditionals and loops
- Simple form handling
- Small app logic and UI patterns

The repository is organized as separate folders, each representing a small exercise or mini project.

## Included Examples

- `TodoList` — simple to-do list interface
- `bookSystem` — book management or catalogue example
- `calculateArea` — JavaScript calculations and area logic
- `colorfulMemoryGame` — interactive memory game using HTML/CSS/JS
- `groceryTracker` — grocery item tracking
- `restaurantMenu` — menu-related logic or UI
- `employeeDetails` — employee data and display exercise
- `followersCount` — counters and data display practice
- `healthArticle` — content/article-related webpage
- `productSurvey` — survey or form-based exercise
- `speedAnalysis` — speed or performance logic example
